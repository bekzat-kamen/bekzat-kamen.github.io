Примеры рабочих артефактов

Кейс: AI-ассистент в мессенджере с Function Calling, бронированием и подтверждением оплаты

Business Analysis / Gherkin

User Story и критерии приёмки (AC)

As a клиент компании,
I want оформлять заказ и получать платежную ссылку прямо в мессенджере через AI-бота,
So that мне не приходилось ожидать ответа оператора для типовых покупок.

AC-1 (Успешная генерация счета): Given клиент подтвердил состав заказа и номер телефона, When LLM классифицирует интент как create_invoice с confidence ≥ 0.85, Then система формирует ссылку через Payment Gateway, отправляет её в чат и запускает таймер ожидания оплаты на 15 минут.
AC-2 (Fallback на оператора): Given AI не смог распознать запрос 2 раза подряд ИЛИ получена жалоба клиента, When срабатывает триггер эскалации, Then бот переводит чат в статус need_operator, ставит задачу менеджеру в CRM с дедлайном 10 минут и отправляет клиенту сообщение о подключении человека.

OpenAPI / JSON Schema

Контракт схемы инструмента (Tool Definition) для вызова функции бэкенда через LLM

{
  "name": "generate_invoice",
  "description": "Генерирует счет на оплату после явного согласия клиента",
  "parameters": {
    "type": "object",
    "properties": {
      "customer_phone": {
        "type": "string",
        "pattern": "^\\+7[0-9]{10}$",
        "description": "Номер телефона в международном формате"
      },
      "tariff_plan": {
        "type": "string",
        "enum": ["starter", "pro", "enterprise"],
        "description": "Выбранный тарифный план"
      },
      "billing_period_months": {
        "type": "integer",
        "enum": [1, 6, 12],
        "default": 1
      }
    },
    "required": ["customer_phone", "tariff_plan"]
  }
}
