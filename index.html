Как я документирую интеграции: живая диаграмма взаимодействия и контракт API

UML Sequence Diagram

Сценарий: Обработка входящего сообщения через WhatsApp и синхронизация с CRM

sequenceDiagram
    autonumber
    actor Client as Клиент (WhatsApp)
    participant Meta as Meta / WABA Gateway
    participant Platform as Integration Gateway
    participant Queue as Redis / Message Queue
    participant CRM as CRM API (amoCRM/Bitrix24)

    Client->>Meta: Входящее сообщение
    Meta->>Platform: Webhook POST /v1/webhooks/whatsapp
    Note over Platform: Проверка X-Hub-Signature & Idempotency Key
    Platform-->>Meta: HTTP 200 OK
    Platform->>Queue: Publish event [message.received]
    
    Queue->>Platform: Consume event
    Platform->>CRM: GET /api/v4/contacts?query=phone
    alt Контакт не найден
        Platform->>CRM: POST /api/v4/contacts & POST /api/v4/leads
        CRM-->>Platform: 201 Created (LeadID: 1042)
    else Контакт найден
        Platform->>CRM: GET /api/v4/leads (Активная сделка)
    end

    Platform->>CRM: POST /api/v4/leads/{id}/notes (Таймлайн чата)
    CRM-->>Platform: 200 OK
